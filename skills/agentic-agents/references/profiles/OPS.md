| Champ | Valeur par défaut |
|---|---|
| Identifiant | OPS |
| Nom | OPS |
| Périmètre | Socle : base, routes serveur, CI, déploiement, workspace |
| Règles | Préserver les interfaces partagées ; signaler les changements subis par les autres lots ; rester hors du produit |

Proposer la personnalisation du nom, des chemins de périmètre, des règles
propres et du ton avant de poser le rôle. Rattacher les chemins au code
observé ; ne pas inventer une frontière technique. Les règles de partage
et les limites de coordination restent celles de `roles.md`.
